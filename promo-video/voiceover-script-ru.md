# Текст диктора — KPI Pulse promo (RU)

Хронометраж: **35 секунд**, 30 fps.  
Речь идёт **без пауз между сценами**. Ролик без голоса читается по субтитрам.

Цифры в кадре — из `data/sample_data.csv`, период **2026-06**.

| Время | Экран | Текст на экране | Закадр |
| --- | --- | --- | --- |
| 0–5 с | Захват | Цифры есть. А что происходит с бизнесом? | Отчёты полны цифр. А что делать с бизнесом — неясно. |
| 5–11 с | Проблема | Выручка. Расходы. Клиенты. Конверсия. | Выручка, расходы, клиенты. Искать вручную — значит опоздать. |
| 11–16 с | Решение | Загрузите таблицу — получите понятную картину бизнеса. | Загрузите таблицу — и получите понятную картину бизнеса. |
| 16–21 с | Польза | Проблемы видны сразу. | Показатели на одном экране. Падение ценности клиента видно сразу. |
| 21–25 с | AI-аналитик | Спросите обычными словами. | Спросите своими словами — получите причину и что делать. |
| 25–30 с | Telegram | Главные показатели всегда под рукой. | Отчёт придёт в Telegram. Цифры всегда под рукой. |
| 30–35 с | Оффер | KPI Pulse — ваш AI-аналитик бизнеса. | KPI Pulse — ваш AI-аналитик бизнеса. Попробуйте. |

## Синтез голоса

```bash
pip install edge-tts
python scripts/generate_voiceover.py
```

Голос: `ru-RU-DmitryNeural`, темп `+15%`.

Рендер с голосом: `npm run build:vo`  
Рендер без голоса: `npm run build:silent`
